# DreamStream Frontend Assets

This folder holds local visual assets for the Angular frontend.

- `images/` is for the DreamStream logo, hero illustration, hands-heart illustration, footer watercolor, and other large visual assets.
- `icons/` is for navigation icons, request icons, and small UI icons.
- Use SVG for logos and icons so they scale cleanly.
- Use PNG or WebP for complex illustrations, painted textures, or layered artwork.
- Do not use one full-page screenshot as the real homepage implementation. The homepage must be built with real Angular HTML and SCSS.

## Active Production Assets

Use these files for the current homepage implementation:

- `images/hero-community.png` is the only active hero image.
- `images/hands-heart.png` is the only active What You Can Do illustration.
- `images/footer-watercolor.png` is the only active footer or impact background image.
- `icons/dreamstream-logo-mark.png` is the active DreamStream logo mark.

## Archived Assets

Files in `images/archive/` are historical, partial, reference, or confusing crops. They must not be used by the homepage implementation unless a future task explicitly promotes one back to an active production asset.
