# DreamStream Design References

## Primary Visual Target

`dreamstream-target-homepage.png` is the primary visual target for the DreamStream homepage redesign.

Use it as the source of truth for the warm, polished, soft, high-quality illustrated nonprofit direction. The intended result should feel human, generous, optimistic, and carefully finished.

## Archived References

Files in `archive/` are historical references only. They may help explain earlier design exploration, but they should not drive the visual style.

Do not copy the flat vector/Figma look from archived screenshots such as `archive/dreamstream-figma-structure.png`.

## Implementation Guidance

Build the page with real Angular HTML and SCSS for layout, structure, responsive behavior, dynamic data, and interactions.

Use image assets for complex illustrations, watercolor textures, layered artwork, or other visuals that should not be recreated with brittle CSS shapes.

Do not implement the homepage as one full-page screenshot.
