# Assets Guide

## Purpose

This document defines the asset strategy for DreamStream frontend design work.

## Recommended Folders

- `frontend/src/assets/images/`
- `frontend/src/assets/icons/`

## Recommended Assets

- `dreamstream-logo.svg`
- `hero-community.png` or `hero-community.svg`
- `hands-heart.png` or `hands-heart.svg`
- `footer-watercolor.png`
- `icon-home.svg`
- `icon-offer-help.svg`
- `icon-request-help.svg`
- `icon-my-requests.svg`
- `icon-profile.svg`
- `icon-laptop.svg`
- `icon-code.svg`
- `icon-hash.svg`

## Asset Format Rules

- Use SVG for logos and simple icons.
- Use PNG or WebP for more complex warm illustrations, painted textures, or layered artwork.
- Prefer SVG when the asset needs to scale cleanly across responsive layouts.
- Keep filenames descriptive and stable.

## Usage Rules

- Do not hardcode external image URLs.
- Store frontend assets locally in the project asset folders.
- Add alt text for meaningful images.
- Decorative images should use empty alt text or CSS backgrounds.
- Avoid using imagery that looks overly corporate, generic stock, or visually cold.

## Design Direction for Assets

- Prioritize illustrations and imagery that suggest community, generosity, welcome, and action.
- Icons should feel simple, friendly, and readable at small sizes.
- Warm background accents such as watercolor, abstract blobs, or soft organic shapes are acceptable when used with restraint.
